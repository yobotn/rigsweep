📖 为什么要做 RigSweep

在 AI 时代，开发用的笔记本电脑早已不只运行一个程序。平常的一天里，不同终端中开着好几个 Claude Code 会话，每个项目一个开发服务器，还有构建监视程序，以及开满文档和预览页面的浏览器。

每个会话都会启动更多进程，其中很多在你关闭终端后仍在运行。任务管理器只显示一长串 node.exe、python.exe 和 chrome.exe，看不出它们属于哪个会话或项目。

然后我看了看磁盘。我当时在同时开发三个 Rust 应用：RigSweep 本身、KeepRun（把 Node、.NET 和 Python 应用作为 Windows 服务持续运行）和 Focuside（一款专注的 AI 编程智能体 IDE）。每个项目的 target 文件夹都涨到了约 40 GB，加起来 约 120 GB，全是 Cargo 从不自动清理的构建产物。开发磁盘标签页一次扫描就把这三个都找了出来。

这些都不是病毒，也不是垃圾，而是用 AI 智能体干活时正常留下的残留，再加上开发机根本用不着的 Windows 后台组件。现有的“电脑加速”软件要么做些吓人又不可撤消的操作，要么对开发工作流一无所知，所以我做了一个自己想要的工具。

RigSweep 让你看清到底是什么在占用电脑，清理闲置的进程，并且每项更改都可以撤消。

🌐 Chrome（37 个进程）6.5 GB
⬢ Node + Claude（14 个进程）2.5 GB
🧩 正在运行的 Windows 服务~150
💾 Rust target 文件夹（3 个项目）~120 GB
在作者的 32 GB 笔记本电脑上于工作日中途测得。
功能

✨ 它能做什么

专为整天和终端、AI 智能体打交道的开发者打造，而不是那些“电脑加速”的花招。一个应用即可替代任务管理器、CPU-Z 这类硬件信息工具和清理软件。

🧹

开发清理

找出 Node、Python、Java、.NET 等技术栈中孤立和空闲的开发服务器、构建守护进程和智能体 CLI，并显示各自的进程树、项目、内存和端口。

💾

开发磁盘

删除你不再碰的项目里的 node_modules、.next、target 和 .venv，清理包缓存、GPU 着色器缓存和 AI 工具缓存，移除智能体留下的 git worktree，清掉 Windows 残留（旧临时文件、更新下载、崩溃转储），并压缩 Docker 和 WSL 虚拟磁盘。点击前就能看到清理后有多少可用空间，还可以每周自动清空会自动重建的缓存。

🤖

给 AI 智能体用

rigsweep --disk-report --json 和 --disk-clean --safe --dry-run 无需管理员权限，rigsweep --mcp 是一个 MCP 服务器：Claude Code、Cursor 或 Codex 可以查看可用空间、看是什么占了它，并清空会自动重建的缓存。

🖥️

硬件

硬盘健康、测速，以及 CPU、显卡、内存和电池信息，一个页面全搞定，不用再开四个工具。无需安装驱动。

🎮

GPU 与 AI

用任务管理器同款计数器显示每个应用在显卡和 NPU 上做什么，还能看到正在运行的 AI 运行时（Ollama、LM Studio、llama.cpp、ComfyUI、PyTorch）、已加载的模型及其占用的显存。

📡

网络

按网卡显示流量，哪个应用占用了哪个连接或监听端口，还能搜索是谁在用 3000 端口或锁住了某个文件或文件夹。

🔍

进程与启动项

显示每个进程的 CPU、内存和磁盘占用、每个 svchost.exe 中的服务，以及任务管理器从不显示的自动启动服务和计划任务。

🪟

控制台弹窗

那个一闪而过的命令提示符窗口：RigSweep 会记录它运行的确切命令、是谁启动了它（计划任务、服务还是应用）以及里面运行了什么，还能关闭背后的计划任务，并留有备份。

🔎

查找

逐个文件夹查看每个驱动器上什么占了空间，把包缓存从 C: 移到其他驱动器或 Dev Drive，并检查没有卸载程序的软件、下载文件夹里又大又旧的文件和未签名的启动程序，一键用 Microsoft Defender 扫描。

📊

提速报告

真实的前后对比测量值，而不是虚假的百分比。你可以将结果复制为 Markdown 并分享出去。

⚙️

可撤消的优化

遥测、Xbox、索引器、后台应用、阻止 Edge 重新安装等，每项都标有风险等级。原始值会先备份，单击一下即可还原。

🧽

浏览器清理

清空 Chrome、Edge、Brave、Vivaldi、Opera 和 Firefox 的缓存。登录状态、Cookie、密码和历史记录绝不会受影响。

🌡️

温度

显示 CPU 和 GPU 温度及最近 5 分钟的趋势，电脑持续过热时会发出警告。无需安装驱动程序，也无需管理员权限。

🌐

Chrome 标签页助手

一个小巧的扩展程序，可以让空闲标签页休眠、关闭重复的标签页，以及按 localhost:* 这样的模式关闭标签页。它没有网络访问权限。

🎛️

简单或专业

简单模式用平实的话显示仪表板和清理。专业模式增加进程、网络、GPU 引擎和原始数据。关闭不需要的监视器后就不占 CPU。

🔄

更新由你决定

默认关闭。你可以随时手动检查，也可以开启每日自动检查。只有在你单击后才会安装更新，并且更新必须经过签名。

🧹 安全清理闲置会话

  • 孤立进程：终端已关闭，但进程仍在运行，比如经典的僵尸 localhost:3000。
  • 打开的终端中的空闲智能体绝不会被预先选中，因为它们正在等你。
  • 编辑器的语言服务器会被锁定（VS Code、Cursor、JetBrains、Visual Studio…）。
  • 按进程树结束，绝不按端口结束。结束前会再次验证每一行，因此绝不会混淆两个项目。
  • 智能体遗留的 MCP 服务器和无头浏览器也能被找出来；每次清理后几秒钟内，实时指示器就会显示你回收了多少内存。

常见问题

❓ 开发者常问的问题

RigSweep 是做什么的？

RigSweep 是一款免费开源的 Windows 应用，面向使用 AI 编程代理的开发者。它能找出关闭终端后仍在运行的开发服务器、构建守护进程、MCP 服务器和代理 CLI，逐个显示其所属项目、内存占用和端口，并结束你选中的进程。它还能删除旧的 node_modules 和包缓存、清空浏览器缓存，并应用可撤销的 Windows 优化。

关闭终端后 node.exe 进程仍在运行，怎么结束？

打开“开发清理”。终端已不存在的进程会被标记为孤立进程并自动选中，同时显示完整的进程树、项目文件夹和监听端口（比如卡住的 localhost:3000）。单击“结束所选项”，RigSweep 会先确认进程 ID 仍属于同一个程序，再结束每个进程树。

支持哪些 AI 代理和开发技术栈？

支持 Claude Code、Codex、Gemini CLI、opencode、Aider 和 Goose，以及它们启动的 MCP 服务器和无头浏览器。开发技术栈：Node、Bun、Deno、Python、Java、Gradle、Maven、.NET、Ruby、PHP、Rust 和 Go，以及 WSL 2 / Docker 虚拟机。

安全吗？可以撤销更改吗？

未经你确认，任何进程都不会被结束，任何文件都不会被删除。每项 Windows 优化都会先备份原始值，可以逐项或一次性全部还原；在第一次更改之前还会创建系统还原点。编辑器的语言服务器和核心 Windows 服务已被锁定，无法更改。

RigSweep 免费吗？会收集数据吗？

是的，它基于 MIT 许可证永久免费，无需账户，也没有广告。RigSweep 会询问一次是否共享匿名使用统计（清理了什么，按类型和大小统计，哪些常见应用占用最多，以及安装了哪些硬件厂商软件）。在你回答之前不会发送任何内容，确切的报告可以在设置中查看，关闭后已发送的数据也会被删除。绝不包含路径、项目名称或个人数据。除非你开启或点击“立即检查”，否则不会检查更新。

能在 macOS 或 Linux 上运行吗？

不能。RigSweep 专为 Windows 10 和 11 打造，因为它要操作 Windows 服务、任务计划程序和 Defender。不过，它仍可以从 Windows 端关闭 WSL 2 虚拟机。
