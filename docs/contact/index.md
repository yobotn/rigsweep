# Contact

> How to reach the RigSweep project: bug reports, feature ideas, security reports and translations, all through GitHub.

RigSweep is an open-source project, so all contact happens in the open on GitHub. That way answers help everyone who has the same question.

## 🐞 Bug reports

Open an issue at [github.com/yobotn/rigsweep/issues](https://github.com/yobotn/rigsweep/issues). Please include your Windows version, the RigSweep version (shown in Settings) and what you expected to happen. A screenshot of the affected tab helps a lot.

## 💡 Feature ideas

Vote with a 👍 on the [feature vote](https://github.com/yobotn/rigsweep/issues/12), or [open a feature request](https://github.com/yobotn/rigsweep/issues/new?template=feature_request.yml) if your idea isn't listed yet.

## 💬 Questions and results

Ask in [GitHub Discussions](https://github.com/yobotn/rigsweep/discussions). Before/after Boost Report results are very welcome there too.

## 🔒 Security issues

Please don't open a public issue for a vulnerability. Report it privately through [GitHub's private vulnerability reporting](https://github.com/yobotn/rigsweep/security/advisories/new).

## 🛡️ Antivirus false positives

If Microsoft Defender flagged or deleted RigSweep, read the [antivirus FAQ](https://github.com/yobotn/rigsweep#%EF%B8%8F-antivirus-false-positives) first. It explains why this happens and how to restore a download from the official Releases page.

## 🌍 Translations

Spotted an awkward phrase in one of the 12 languages? Pull requests on `ui/locales`, `docs/locales` or the README files are welcome.
