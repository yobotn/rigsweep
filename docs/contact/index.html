Contact

RigSweep is an open-source project, so all contact happens in the open on GitHub. That way answers help everyone who has the same question.

🐞 Bug reports

Open an issue at github.com/yobotn/rigsweep/issues. Please include your Windows version, the RigSweep version (shown in Settings) and what you expected to happen. A screenshot of the affected tab helps a lot.

💡 Feature ideas

Vote with a 👍 on the feature vote, or open a feature request if your idea isn't listed yet.

💬 Questions and results

Ask in GitHub Discussions. Before/after Boost Report results are very welcome there too.

🔒 Security issues

Please don't open a public issue for a vulnerability. Report it privately through GitHub's private vulnerability reporting.

🛡️ Antivirus false positives

If Microsoft Defender flagged or deleted RigSweep, read the antivirus FAQ first. It explains why this happens and how to restore a download from the official Releases page.

🌍 Translations

Spotted an awkward phrase in one of the 10 languages? Pull requests on ui/locales, docs/locales or the README files are welcome.
