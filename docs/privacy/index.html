Privacy policy

Last updated: November 11, 2026

Short version: RigSweep collects nothing. It has no telemetry, no analytics, no crash reporting and no account.

The app

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. The only network request RigSweep can make is the update check, and only when you ask for it: clicking Check now in Settings, or turning on Check for updates automatically (off by default). It downloads latest.json from the project's GitHub Releases and sends nothing about your PC. An update is installed only after you click Install, and only if its signature matches RigSweep's signing key. Like any download, that request is handled by GitHub under GitHub's privacy statement.

What is stored on your PC

Backups of original Windows settings, cleanup history and before/after measurements are stored locally in %ProgramData%\RigSweep\rigsweep.db. Nothing is uploaded. Uninstalling RigSweep and deleting that folder removes it all.

The Chrome tab helper

The optional extension uses only the tabs, storage and alarms permissions and makes no network requests. Its settings stay in your browser.

This website

rigsweep.com is a static site hosted on GitHub Pages. It sets no cookies and runs no analytics or ads. The only thing it stores is your language choice, in your browser's local storage. GitHub may keep standard server logs (such as IP addresses) as described in its privacy statement.
