# 에이전트를 위한 여유 공간.

> AI 에이전트 세션으로 어수선해진 개발 PC의 RAM, CPU, 디스크를 확보하는 무료 오픈 소스 Windows 앱입니다. 남아 있는 개발 서버, MCP 서버, 에이전트 CLI를 종료하고, 오래된 node_modules와 패키지·AI 도구 캐시를 삭제하며, 되돌릴 수 있는 Windows 설정과 실제 전후 측정 보고서를 제공합니다.

AI 에이전트 세션, 잊고 있던 개발 서버, Windows 백그라운드 서비스로 가득 찬 Windows 개발 PC의 RAM과 CPU를 확보하세요. 모든 변경 사항은 되돌릴 수 있습니다.

지금까지 RigSweep 사용자가 확보한 것

익명 통계를 공유하는 사용자들의 실시간 합계

## Node만이 아닙니다

개발 정리는 실제로 사용하는 스택 전반에서 남아 있는 개발 서버, 빌드 데몬, 에이전트 세션을 찾아내고, 조용히 수 GB를 차지하는 WSL 2 / Docker VM도 찾아냅니다.

## 📖 만든 이유

AI 시대의 개발용 노트북은 더 이상 한 가지만 실행하지 않습니다. 평범한 하루에도 여러 터미널에서 Claude Code 세션 몇 개, 프로젝트마다 개발 서버, 빌드 감시 프로세스, 문서와 미리 보기로 가득 찬 브라우저가 실행됩니다.

세션마다 프로세스가 늘어나고, 그중 상당수는 터미널을 닫은 후에도 계속 실행됩니다. 작업 관리자에는 node.exe, python.exe, chrome.exe만 잔뜩 표시될 뿐, 어느 세션이나 프로젝트의 것인지는 알 수 없습니다.

다음으로 디스크를 확인했습니다. 저는 Rust 앱 세 개를 동시에 개발하고 있었습니다. RigSweep 자체와 [KeepRun](https://github.com/yobotn/keeprun)(Node, .NET, Python 앱을 Windows 서비스로 계속 실행해 주는 도구), [Focuside](https://github.com/yobotn/focuside)(AI 코딩 에이전트를 위한 집중형 IDE)입니다. 프로젝트마다 `target` 폴더가 약 **40GB**까지 커져서 모두 합치면 **약 120GB**였고, 전부 Cargo가 알아서 정리해 주지 않는 빌드 결과물이었습니다. 게다가 프로젝트 하나에만 git worktree가 약 **30GB** 쌓여 있었습니다. 에이전트가 병렬 작업용으로 만든 추가 체크아웃으로, 저마다 빌드 결과물을 따로 가지고 있었고 작업을 병합한 지 한참 지나서도 그대로 남아 있었습니다. **개발 디스크** 탭은 한 번의 검사로 이 모두를 찾아냈습니다.

바이러스도 쓰레기도 아니었습니다. AI 에이전트와 일하면 으레 남는 것들, 그리고 개발용 PC에는 필요 없는 Windows 백그라운드 작업이었습니다. 기존 'PC 최적화' 앱은 되돌릴 수 없는 위험한 일을 하거나 개발 작업 방식을 전혀 몰랐습니다. 그래서 제가 쓰고 싶은 도구를 직접 만들었습니다.

**RigSweep은 PC를 실제로 무엇이 사용하고 있는지 보여 주고, 방치된 항목을 정리하며, 모든 변경 사항을 되돌릴 수 있게 유지합니다.**

## ✨ 주요 기능

'PC 최적화' 꼼수가 아니라, 터미널과 AI 에이전트로 일하는 개발자를 위해 만들었습니다. 작업 관리자, CPU-Z 같은 하드웨어 정보 도구, 정리 프로그램을 앱 하나로 대신합니다.

### 개발 정리

Node, Python, Java, .NET 등에서 분리되었거나 유휴 상태인 개발 서버, 빌드 데몬, 에이전트 CLI를 프로세스 트리, 프로젝트, RAM, 포트와 함께 보여 줍니다.

### 개발 디스크

손대지 않는 프로젝트의 node_modules, .next, target, .venv를 지우고, 패키지·GPU 셰이더·AI 도구 캐시를 정리하고, 에이전트가 남긴 git worktree를 없애고, Windows 찌꺼기(오래된 임시 파일, 업데이트 다운로드, 크래시 덤프)를 치우고, Docker와 WSL 가상 디스크를 줄입니다. 누르기 전에 여유 공간이 얼마가 될지 보여 주고, 저절로 다시 만들어지는 캐시는 매주 자동으로 비울 수 있습니다.

### AI 에이전트용

rigsweep --disk-report --json과 --disk-clean --safe --dry-run은 관리자 권한 없이 동작하고, rigsweep --mcp는 MCP 서버입니다. Claude Code, Cursor, Codex가 여유 공간을 확인하고, 무엇이 차지하는지 보고, 저절로 다시 만들어지는 캐시를 비울 수 있습니다.

### 하드웨어

디스크 상태, 속도 테스트, CPU·GPU·RAM·배터리 정보를 도구 4개 대신 탭 하나에서 확인하세요. 드라이버 설치는 필요 없습니다.

### GPU 및 AI

각 앱이 그래픽 카드와 NPU에서 하는 일을 작업 관리자와 같은 카운터로 보여 주고, 실행 중인 AI 런타임(Ollama, LM Studio, llama.cpp, ComfyUI, PyTorch), 로드된 모델, 사용 중인 비디오 메모리도 보여 줍니다.

### 네트워크

어댑터별 트래픽, 어떤 앱이 어떤 연결이나 수신 대기 포트를 쓰는지, 그리고 포트 3000이나 잠긴 파일·폴더를 누가 쓰는지 알려 주는 검색.

### 프로세스와 시작 프로그램

프로세스별 CPU, RAM, 디스크 사용량, 각 svchost.exe 안의 서비스, 그리고 작업 관리자에는 나오지 않는 자동 시작 서비스와 작업을 보여 줍니다.

### 콘솔 창

번쩍 떴다가 사라지는 그 명령 프롬프트 창. RigSweep이 실제로 실행된 명령, 무엇이 시작했는지(예약된 작업, 서비스 또는 앱), 안에서 무엇이 실행됐는지 기록하고, 그 뒤에 있는 작업을 백업과 함께 끌 수 있습니다.

### 찾기

드라이브마다 무엇이 공간을 차지하는지 폴더별로 보고, 패키지 캐시를 C:에서 다른 드라이브나 Dev Drive로 옮기고, 제거 프로그램이 없거나 작동하지 않는 프로그램, 다운로드 폴더의 오래된 큰 파일, 서명 없는 시작 프로그램을 Microsoft Defender 검사와 함께 살펴볼 수 있습니다.

### 부스트 보고서

가짜 퍼센트 대신 실제로 측정한 전후 값을 보여 줍니다. Markdown으로 복사해 결과를 공유할 수 있습니다.

### 되돌릴 수 있는 시스템 조정

원격 분석, Xbox, 인덱서, 백그라운드 앱, Edge 재설치 방지 등을 위험 수준과 함께 제공합니다. 원래 값은 백업되며 클릭 한 번으로 복원할 수 있습니다.

### 브라우저 정리

Chrome, Edge, Brave, Vivaldi, Opera, Firefox의 캐시를 비웁니다. 로그인, 쿠키, 암호, 방문 기록은 절대 건드리지 않습니다.

### 온도

CPU와 GPU 온도를 5분 추세와 함께 보여 주고, PC가 계속 뜨거우면 경고합니다. 드라이버나 관리자 권한이 필요 없습니다.

### Chrome 탭 도우미

유휴 탭을 절전 모드로 전환하고, 중복 탭을 닫고, localhost:* 같은 패턴으로 탭을 닫는 작은 확장 프로그램입니다. 네트워크 액세스 권한이 없습니다.

### 간단 또는 프로

간단 모드는 대시보드와 정리를 쉬운 말로 보여 줍니다. 프로 모드는 프로세스, 네트워크, GPU 엔진, 원시 수치를 더합니다. 필요 없는 모니터를 끄면 CPU를 쓰지 않습니다.

### 업데이트는 원할 때만

기본적으로 꺼져 있습니다. 원할 때 확인하거나 매일 확인하도록 켜세요. 업데이트는 클릭할 때만, 그리고 서명된 경우에만 설치됩니다.

### 11개 언어

앱, 설치 프로그램, Chrome 확장 프로그램에서 English, Deutsch, Español, Français, Italiano, Português, Русский, 日本語, 한국어, 简体中文, العربية을 지원하며, 각 언어의 공식 Windows 용어를 사용합니다.

## 🧹 방치된 세션을 안전하게 정리

- **분리된 프로세스**: 터미널은 닫혔지만 계속 실행 중인 프로세스입니다. 전형적인 좀비 localhost:3000이 그 예입니다.
- **열린 터미널의 유휴 에이전트는 미리 선택되지 않습니다**. 사용자를 기다리는 중이기 때문입니다.
- **편집기 언어 서버는 잠겨 있습니다**(VS Code, Cursor, JetBrains, Visual Studio…).
- **포트가 아니라 프로세스 트리 단위로 종료합니다.** 종료 직전에 각 행을 다시 확인하므로 두 프로젝트를 혼동하는 일이 없습니다.
- **에이전트가 남기고 간 MCP 서버와 헤드리스 브라우저**도 찾아내며, 정리 후 몇 초 만에 실시간 측정기로 확보된 RAM을 보여 줍니다.

## 🛟 모든 변경 사항을 되돌릴 수 있습니다

- 첫 변경 전에 **원래 값을 SQLite에 백업**합니다.
- 처음 적용하기 전에 **시스템 복원 지점**을 만듭니다.
- **감시 기능**이 Windows 업데이트가 몰래 되돌린 조정을 다시 적용합니다.
- Windows 업데이트, Defender 엔진, 약 60개의 핵심 서비스는 **절대 건드리지 않습니다**.

## 🛡️ Defender가 삭제했나요?

RigSweep은 오픈 소스이지만 아직 코드 서명이 되어 있지 않습니다. 서비스를 변경하는 도구는 머신 러닝 휴리스틱에 맬웨어처럼 보이기 때문에 Defender가 실수로 감지할 수 있습니다(예: `Trojan:Win32/Bearfoos!ml`, 여기서 `!ml`은 휴리스틱 추정을 뜻합니다).

설치 프로그램은 자체 폴더만 제외할지 **묻고**, 제거 프로그램은 그 제외 항목을 다시 제거합니다. SignPath Foundation을 통한 코드 서명이 예정되어 있습니다. [전체 FAQ 읽기 →](https://github.com/yobotn/rigsweep/blob/main/README.ko.md#%EB%B0%94%EC%9D%B4%EB%9F%AC%EC%8A%A4-%EB%B0%B1%EC%8B%A0-%EC%98%A4%ED%83%90%EC%A7%80)

## ❓ 개발자들이 자주 묻는 질문

### RigSweep은 어떤 앱인가요?

RigSweep은 AI 코딩 에이전트로 작업하는 개발자를 위한 무료 오픈 소스 Windows 앱입니다. 터미널을 닫은 뒤에도 계속 실행되는 개발 서버, 빌드 데몬, MCP 서버, 에이전트 CLI를 찾아 각각의 프로젝트, RAM, 포트와 함께 보여 주고, 선택한 항목을 종료합니다. 오래된 node_modules와 패키지 캐시를 삭제하고, 브라우저 캐시를 비우고, 되돌릴 수 있는 Windows 설정 조정도 적용합니다.

### 터미널을 닫은 뒤에도 계속 실행되는 node.exe 프로세스는 어떻게 멈추나요?

개발 정리를 여세요. 터미널이 사라진 프로세스는 분리된 프로세스로 표시되고 미리 선택되며, 전체 프로세스 트리, 프로젝트 폴더, 수신 대기 포트(예: 멈춘 localhost:3000)도 함께 표시됩니다. 선택 항목 종료를 클릭하면 RigSweep이 프로세스 ID가 여전히 같은 프로그램의 것인지 확인한 뒤 각 트리를 종료합니다.

### 어떤 AI 에이전트와 개발 스택을 지원하나요?

Claude Code, Codex, Gemini CLI, opencode, Aider, Goose와 이들이 실행하는 MCP 서버 및 헤드리스 브라우저를 지원합니다. 개발 스택은 Node, Bun, Deno, Python, Java, Gradle, Maven, .NET, Ruby, PHP, Rust, Go, 그리고 WSL 2 / Docker VM입니다.

### 안전한가요? 변경 사항을 되돌릴 수 있나요?

확인 없이 종료하거나 삭제하는 것은 없습니다. 모든 Windows 설정 조정은 먼저 원래 값을 백업하므로 하나씩 또는 한 번에 모두 복원할 수 있으며, 첫 변경 전에 시스템 복원 지점이 만들어집니다. 편집기의 언어 서버와 핵심 Windows 서비스는 잠겨 있습니다.

### RigSweep은 무료인가요? 데이터를 수집하나요?

네, MIT 라이선스로 앞으로도 계속 무료이며 계정도 광고도 없습니다. RigSweep은 익명 사용 통계(정리한 항목의 유형과 크기,자원을 가장 많이 쓰는 잘 알려진 앱, 설치된 하드웨어 제조사 소프트웨어)를 공유할지 한 번 묻습니다. 답하기 전에는 아무것도 보내지 않고, 실제 보고서는 설정에서 볼 수 있으며, 끄면 보낸 데이터도 삭제됩니다. 경로, 프로젝트 이름, 개인 정보는 절대 포함되지 않습니다. 업데이트 확인은 직접 켜거나 지금 확인을 클릭하지 않는 한 꺼져 있습니다.

### macOS나 Linux에서도 실행되나요?

아니요. RigSweep은 Windows 서비스, 작업 스케줄러, Defender를 다루기 때문에 Windows 10 및 11용으로 만들어졌습니다. 그래도 Windows 쪽에서 WSL 2 VM을 종료할 수는 있습니다.

## ⚠️ 고지 사항

RigSweep은 Windows 서비스, 예약된 작업, 레지스트리 정책, Microsoft Defender 설정을 변경하며 실행 중인 프로세스를 종료할 수 있습니다. 모든 조정 항목은 백업되어 복원할 수 있고 사용자가 확인하기 전에는 아무것도 변경되지 않지만, 사용에 따른 책임은 사용자에게 있습니다. 이 소프트웨어는 어떠한 종류의 보증도 없이 "있는 그대로" 제공됩니다(MIT 라이선스). 각 변경 사항을 적용하기 전에 검토하고, 별도로 백업을 유지하며, 회사나 학교에서 관리하는 장치에서는 IT 팀의 승인 없이 사용하지 마세요. RigSweep은 독립 프로젝트로 Microsoft, Google, Anthropic, OpenAI 및 언급된 다른 어떤 도구와도 관련이 없습니다. 모든 상표는 해당 소유자의 자산입니다.

## 🚀 에이전트에게 여유 공간을

설치하고, 기준값을 측정하고, 정리한 다음, 다시 측정하세요.

### 🔏 코드 서명

SignPath.io에서 무료 코드 서명을 제공하며, 인증서는 SignPath Foundation에서 발급합니다(신청 진행 중이며 현재 릴리스는 아직 서명되지 않았습니다). 설치 프로그램은 GitHub Actions가 태그된 소스에서 빌드합니다. 원격 분석과 사용 통계 수집이 없습니다. 유일한 네트워크 요청은 업데이트 확인이며, 사용자가 이를 켜거나 지금 확인을 클릭할 때만 발생합니다.
