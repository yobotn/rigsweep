# مساحة لوكلائك.

> تطبيق Windows مجاني ومفتوح المصدر يحرّر الذاكرة والمعالج والقرص في أجهزة المطورين: يُنهي خوادم التطوير وخوادم MCP وأدوات CLI للوكلاء التي بقيت تعمل، ويحذف مجلدات node_modules القديمة وذاكرات التخزين المؤقت للحزم وأدوات الذكاء الاصطناعي، مع تعديلات قابلة للتراجع وقياسات حقيقية قبل وبعد.

حرّر ذاكرة RAM وموارد CPU على أجهزة التطوير العاملة بنظام Windows التي تزدحم بجلسات وكلاء الذكاء الاصطناعي وخوادم التطوير المنسية وخدمات Windows الخلفية. وكل تغيير قابل للتراجع.

ما حرّره مستخدمو RigSweep حتى الآن

مجاميع حية ممن يشاركون إحصاءات مجهولة الهوية

## ليس Node وحده

يعثر «تنظيف التطوير» على خوادم التطوير وعمليات البناء الخلفية وجلسات الوكلاء المتبقية في البيئات التي تستخدمها فعلاً، إضافةً إلى الجهاز الظاهري لـ WSL 2 / Docker الذي يستهلك غيغابايتات بصمت.

## 📖 لماذا وُجد

في عصر الذكاء الاصطناعي، لم يعد كمبيوتر المطوّر المحمول يشغّل شيئًا واحدًا فقط. اليوم العادي يعني عدة جلسات Claude Code في وحدات طرفية مختلفة، وخادم تطوير لكل مشروع، ومراقبي بناء، ومتصفحًا مليئًا بالوثائق والمعاينات.

كل جلسة تُنشئ مزيدًا من العمليات، ويستمر كثير منها في العمل بعد إغلاق الوحدة الطرفية. ولا تعرض «إدارة المهام» سوى جدار من node.exe وpython.exe وchrome.exe، دون أي إشارة إلى الجلسة أو المشروع الذي تنتمي إليه.

ثم ألقيت نظرة على القرص. كنت أطوّر ثلاثة تطبيقات Rust في الوقت نفسه: RigSweep نفسه، و[KeepRun](https://github.com/yobotn/keeprun) (يُبقي تطبيقات Node و.NET وPython قيد التشغيل كخدمات Windows)، و[Focuside](https://github.com/yobotn/focuside) (بيئة تطوير مركّزة لوكلاء البرمجة بالذكاء الاصطناعي). تضخّم مجلد `target` في كل مشروع إلى نحو **40 GB**، أي **~120 GB** في المجموع، وكلها مخرجات بناء لا ينظّفها Cargo من تلقاء نفسه أبدًا. وفوق ذلك، كان في مشروع واحد وحده نحو **30 GB** من git worktrees: نسخ عمل إضافية أنشأها الوكلاء لمهام متوازية، لكل منها مخرجات بنائها الخاصة، وبقيت هناك بعد دمج العمل بوقت طويل. وقد عثر تبويب **قرص التطوير** على كل ذلك في فحص واحد.

لم يكن أيٌّ من ذلك فيروسًا أو ملفات عديمة الفائدة. كانت مجرد البقايا المعتادة للعمل مع وكلاء الذكاء الاصطناعي، إضافةً إلى أشياء تعمل في خلفية Windows لا يحتاجها جهاز المطوّر. أما تطبيقات «تسريع الكمبيوتر» الموجودة، فإما أنها تفعل أشياء مخيفة لا رجعة فيها، وإما أنها لا تعرف شيئًا عن طريقة عمل المطورين، لذلك بنيت الأداة التي كنت أريدها.

**يُظهر RigSweep ما يستخدم جهازك فعلاً، ويكنس ما أصبح متروكًا، ويُبقي كل تغيير قابلاً للتراجع.**

## ✨ ما الذي يفعله

مصمم للمطورين الذين يعيشون في الوحدات الطرفية ومع وكلاء الذكاء الاصطناعي، لا لحيل «تسريع الكمبيوتر». تطبيق واحد بدلًا من إدارة المهام وأداة معلومات العتاد مثل CPU-Z وبرنامج التنظيف.

### تنظيف التطوير

خوادم التطوير وعمليات البناء الخلفية وأدوات CLI للوكلاء اليتيمة والخاملة في Node وPython وJava و‎.NET وغيرها، كلٌّ منها مع شجرة عملياته ومشروعه وذاكرة RAM والمنافذ.

### قرص التطوير

يحذف node_modules و.next وtarget و.venv في المشاريع التي توقفت عن العمل عليها، وينظّف ذاكرات الحزم وshaders الـ GPU وأدوات الذكاء الاصطناعي، ويزيل git worktrees التي تركها الوكلاء، ويمسح مخلّفات Windows (الملفات المؤقتة القديمة، وتنزيلات التحديثات، وملفات الأعطال) ويقلّص أقراص Docker وWSL الافتراضية. ترى قبل النقر كم ستصبح المساحة المتاحة، ويمكنه إفراغ الذاكرات التي تُعاد بناؤها وحدها كل أسبوع.

### لوكلاء الذكاء الاصطناعي

يعمل rigsweep --disk-report --json و‎--disk-clean --safe --dry-run دون صلاحيات المسؤول، وrigsweep --mcp خادم MCP: يمكن لـ Claude Code أو Cursor أو Codex معرفة المساحة المتاحة وما يشغلها وإفراغ الذاكرات التي تُعاد بناؤها وحدها.

### الأجهزة

سلامة الأقراص، واختبار سرعة القرص، وتفاصيل CPU وGPU وRAM والبطارية في علامة تبويب واحدة بدلاً من أربع أدوات منفصلة. بلا تثبيت أي برنامج تشغيل.

### GPU والذكاء الاصطناعي

ما يفعله كل تطبيق على بطاقة الرسومات ووحدة NPU، من العدادات نفسها التي يستخدمها إدارة المهام، إضافة إلى بيئات الذكاء الاصطناعي التي تعمل الآن (Ollama وLM Studio وllama.cpp وComfyUI وPyTorch) والنماذج المحمّلة وذاكرة الفيديو التي تشغلها.

### الشبكة

حركة البيانات لكل محوّل، وأي تطبيق يحتفظ بأي اتصال أو منفذ استماع، وبحث يخبرك بمن يستخدم المنفذ 3000 أو يقفل ملفًا أو مجلدًا.

### العمليات وبدء التشغيل

استخدام CPU وRAM والقرص لكل عملية، والخدمات داخل كل svchost.exe، والخدمات والمهام التي تبدأ تلقائيًا ولا تعرضها إدارة المهام أبدًا.

### نوافذ الطرفية

نافذة موجه الأوامر تلك التي تومض ثم تختفي: يسجّل RigSweep الأمر الذي شغّلته بالضبط، وما الذي شغّلها (مهمة مجدولة أو خدمة أو تطبيق)، وما الذي عمل بداخلها، ويمكنه إيقاف المهمة التي تقف وراءها مع نسخة احتياطية.

### البحث

اعرف ما الذي يشغل المساحة على كل قرص مجلدًا بعد مجلد، وانقل ذاكرات الحزم من C: إلى قرص آخر أو Dev Drive، وراجع البرامج التي فقدت أداة إلغاء التثبيت أو صارت أداتها لا تفعل شيئًا، والملفات الكبيرة القديمة في التنزيلات، وبرامج بدء التشغيل غير الموقّعة، مع فحص Microsoft Defender بنقرة.

### تقرير التسريع

قياسات حقيقية قبل وبعد بدلاً من نسب مئوية زائفة. يمكنك نسخها بتنسيق Markdown ومشاركة نتيجتك.

### تحسينات قابلة للتراجع

القياس عن بُعد وXbox والفهرسة وتطبيقات الخلفية ومنع عودة Edge وغيرها، ولكلٍّ منها مستوى خطورة. تُنسخ القيم الأصلية احتياطيًا ويمكن استعادتها بنقرة واحدة.

### تنظيف المتصفحات

يفرّغ ذاكرات التخزين المؤقت لكلٍّ من Chrome وEdge وBrave وVivaldi وOpera وFirefox. لا يتم المساس أبدًا بعمليات تسجيل الدخول أو ملفات تعريف الارتباط أو كلمات المرور أو سجل التصفح.

### درجات الحرارة

درجات حرارة CPU وGPU مع اتجاه لآخر 5 دقائق وتحذير عندما يظل الكمبيوتر ساخنًا. بلا برنامج تشغيل، وبلا صلاحيات المسؤول.

### مساعد علامات التبويب في Chrome

إضافة صغيرة لتنويم علامات التبويب الخاملة، وإغلاق المكررة، وإغلاق علامات التبويب حسب نمط مثل localhost:*. وهي بلا أي وصول إلى الشبكة.

### بسيط أو احترافي

الوضع البسيط يعرض لوحة المعلومات وعمليات التنظيف بكلمات واضحة. والاحترافي يضيف العمليات والشبكة ومحركات GPU والأرقام الخام. أوقف المراقبات التي لا تحتاجها كي لا تستهلك المعالج.

### التحديثات باختيارك

معطّلة افتراضيًا. تحقّق متى شئت، أو شغّل التحقق اليومي. لا تُثبَّت التحديثات إلا عندما تنقر، وبشرط أن تكون موقّعة.

### 11 لغة

English وDeutsch وEspañol وFrançais وItaliano وPortuguês وРусский و日本語 و한국어 و简体中文 والعربية في التطبيق وبرنامج التثبيت وإضافة Chrome، باستخدام مصطلحات Windows الرسمية لكل لغة.

## 🧹 اكنس الجلسات المتروكة بأمان

- **العمليات اليتيمة**: أُغلقت وحدتها الطرفية لكنها ما زالت تعمل، مثل localhost:3000 الزومبي الشهير.
- **لا يتم أبدًا تحديد الوكلاء الخاملين في الوحدات الطرفية المفتوحة مسبقًا**، لأنهم ينتظرونك.
- **خوادم اللغة الخاصة بالمحررات مقفلة** (VS Code وCursor وJetBrains وVisual Studio…).
- **يُنهي العمليات حسب شجرة العمليات، لا حسب المنفذ أبدًا.** ويُعاد التحقق من كل صف قبل إنهائه مباشرةً، فلا يحدث خلط بين مشروعين أبدًا.
- **يعثر أيضًا على خوادم MCP والمتصفحات دون واجهة التي خلّفها وكلاؤك**، ويعرض مقياس مباشر ذاكرة RAM التي استعدتها بعد ثوانٍ من كل تنظيف.

## 🛟 يمكن التراجع عن كل تغيير

- **تُنسخ القيم الأصلية احتياطيًا** في SQLite قبل أول تغيير.
- **نقطة استعادة النظام** قبل أول تطبيق.
- **المراقب** يعيد تطبيق التحسينات التي أعادها Windows Update بصمت.
- **لا يمس أبدًا** Windows Update أو محرك Defender أو نحو 60 خدمة أساسية.

## 🛡️ هل حذفه Defender؟

إن RigSweep مفتوح المصدر لكنه غير موقّع رقميًا بعد. وتبدو الأدوات التي تغيّر الخدمات كالبرامج الضارة في نظر خوارزميات التعلم الآلي، لذا قد يصنّفه Defender خطأً (مثل `Trojan:Win32/Bearfoos!ml`، حيث تعني `!ml` تخمينًا استدلاليًا).

**يسألك** برنامج التثبيت ما إذا كنت تريد استثناء مجلده وحده، ويزيل برنامج إلغاء التثبيت هذا الاستثناء لاحقًا. ومن المخطط توقيع التعليمات البرمجية عبر SignPath Foundation. ## ❓ أسئلة يطرحها المطورون

### ما الذي يفعله RigSweep؟

RigSweep تطبيق مجاني ومفتوح المصدر لنظام Windows، مخصص للمطورين الذين يعملون مع وكلاء البرمجة بالذكاء الاصطناعي. يعثر على خوادم التطوير وعمليات البناء الخلفية وخوادم MCP وأدوات CLI للوكلاء التي تستمر في العمل بعد إغلاق الوحدة الطرفية، ويعرض كلاً منها مع مشروعه وذاكرة RAM والمنافذ، ويُنهي ما تختاره منها. كما يحذف مجلدات node_modules القديمة وذاكرات التخزين المؤقت للحزم، ويفرّغ ذاكرات التخزين المؤقت للمتصفحات، ويطبّق تحسينات Windows قابلة للتراجع.

### كيف أوقف عمليات node.exe التي تستمر في العمل بعد إغلاق الوحدة الطرفية؟

افتح «تنظيف التطوير». تُعلَّم العمليات التي اختفت وحدتها الطرفية على أنها يتيمة وتُحدَّد مسبقًا، مع شجرة عملياتها الكاملة ومجلد مشروعها والمنافذ التي تستمع عليها (مثل localhost:3000 العالق). انقر فوق «إنهاء المحدد»، وسيُنهي RigSweep كل شجرة بعد التحقق من أن معرّف العملية لا يزال يخص البرنامج نفسه.

### ما وكلاء الذكاء الاصطناعي وبيئات التطوير التي يدعمها؟

Claude Code وCodex وGemini CLI وopencode وAider وGoose، إضافةً إلى خوادم MCP والمتصفحات دون واجهة التي تشغّلها. أما بيئات التطوير فهي: Node وBun وDeno وPython وJava وGradle وMaven و‎.NET وRuby وPHP وRust وGo، والجهاز الظاهري لـ WSL 2 / Docker.

### هل هو آمن؟ وهل يمكنني التراجع عن التغييرات؟

لا يتم إنهاء أو حذف أي شيء دون تأكيدك. ينسخ كل تحسين لـ Windows القيمة الأصلية احتياطيًا أولاً، ويمكن استعادة التحسينات واحدًا تلو الآخر أو كلها دفعة واحدة، كما تُنشأ نقطة استعادة النظام قبل أول تغيير. وخوادم اللغة الخاصة بالمحررات وخدمات Windows الأساسية مقفلة.

### هل RigSweep مجاني؟ وهل يجمع بيانات؟

نعم، إنه مجاني للأبد بموجب ترخيص MIT، بلا حساب وبلا إعلانات. يسألك RigSweep مرة واحدة عن مشاركة إحصاءات استخدام مجهولة الهوية (ما نظّفه حسب النوع والحجم،وأي التطبيقات المعروفة تستهلك أكثر، وأي برامج مصنّعي العتاد مثبّتة). لا يُرسَل أي شيء قبل أن تجيب، ويظهر التقرير كما هو في الإعدادات، وإيقافها يحذف ما أُرسل. لا يتضمن أبدًا مسارات أو أسماء مشاريع أو بيانات شخصية. يبقى التحقق من التحديثات متوقفًا ما لم تفعّله أو تنقر على تحقق الآن.

### هل يعمل على macOS أو Linux؟

لا. صُمم RigSweep لنظامي Windows 10 و11، لأنه يتعامل مع خدمات Windows وبرنامج جدولة المهام وDefender. ومع ذلك يمكنه إيقاف تشغيل الجهاز الظاهري لـ WSL 2 من جانب Windows.

## ⚠️ إخلاء المسؤولية

يُجري RigSweep تغييرات على خدمات Windows والمهام المجدولة ونُهج السجل وإعدادات Microsoft Defender، ويمكنه إنهاء العمليات قيد التشغيل. يُنسخ كل تحسين احتياطيًا ويمكن استعادته، ولا يحدث أي شيء دون تأكيدك، لكن استخدامه يكون على مسؤوليتك الخاصة. يتم توفيره «كما هو» دون أي ضمان من أي نوع (ترخيص MIT). راجع كل تغيير قبل تطبيقه، واحتفظ بنسخك الاحتياطية الخاصة، ولا تستخدمه على أجهزة تديرها جهة عملك أو مدرستك دون موافقة فريق تكنولوجيا المعلومات. RigSweep مشروع مستقل لا يتبع Microsoft أو Google أو Anthropic أو OpenAI أو أي أداة أخرى يذكرها، وجميع العلامات التجارية مملوكة لأصحابها.

### 🔏 توقيع التعليمات البرمجية

توقيع التعليمات البرمجية مجاني مقدّم من SignPath.io، والشهادة من SignPath Foundation (الطلب قيد المعالجة؛ الإصدارات الحالية غير موقّعة بعد). تُنشأ برامج التثبيت من المصدر الموسوم بواسطة GitHub Actions. لا قياس عن بُعد ولا تحليلات. طلب الشبكة الوحيد هو التحقق من وجود تحديثات، وذلك فقط إذا شغّلته أو نقرت فوق «التحقق الآن».
