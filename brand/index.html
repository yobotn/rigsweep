One mark: the sweep.

Everything RigSweep ships with a face: the app and installer icon, the site favicon, the Chrome extension and the social card. Tune it here, check it at every size, and write it all into the repo in one click. The broom comes from Microsoft's Fluent Emoji (MIT), so it matches the emoji Windows already shows next to the name.

App icon

One source, every size. The 1024 px master feeds tauri icon (installer, .ico, taskbar); the small sizes are drawn natively so 16 and 32 px stay sharp.

3D art is 256 px; the 1024 master is upscaled and soft. Use Color for the master.

Color

Dark first. Blue does the work, green confirms it, and the blue-to-green sweep is the signature in both site looks. Click a swatch to copy its hex.

Typography

Native Windows type: Segoe UI Variable, so RigSweep reads like part of the OS. Arabic uses bundled Cairo (OFL); CJK and Cyrillic use the Windows system fonts. Code and paths use Consolas.

Name and voice

RigSweep: one word, capital R and S. Tagline: Room for your agents.

Say it like this

  • Plain verbs: free up, end, delete, undo.
  • Real numbers: "Free 3.8 GB", measured before and after.
  • Safety up front: every change is reversible; say so.
  • Windows' own words in each language, never a literal translation.

Avoid

  • Hype: "supercharge", "blazing", "ultimate".
  • Fear: no fake warnings or scare counts.
  • Boost-era leftovers: no ⚡, no "aiBoost".
  • Redrawing the broom: use the Fluent art as is.

Mark usage

  • Clear space: a quarter of the tile on every side.
  • Minimum: 16 px (Flat broom).
  • Next to the name: broom first, then "RigSweep" in 700 weight.
  • In text: the 🧹 emoji is fine; Windows draws the same Fluent broom.
